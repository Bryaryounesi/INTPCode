# CV-Foundations: Data Skills for Computer Vision

## Project Path Explanation

This project was originally designed as a three-month learning path for general machine learning preparation. After two months, the learning focus shifted to **Computer Vision (CV)**.

The completed portion of the project (Month 1 and Month 2) covers **core data skills, basic math, and data visualization**, which are fully aligned with the new Computer Vision path. These two months provide the foundational skills needed for image data processing and dataset preparation in CV projects.

Although the original three-month plan was discontinued, the completed two months remain **useful and applicable**, serving as an essential preparatory step for the Computer Vision journey.

## Achieved Goals in the First Two Months

- **Data handling with Pandas**: reading data, selecting and filtering rows/columns, sorting, handling missing values  
- **Data merging and management**: merge, concat  
- **Data visualization with Matplotlib**: line plots, histograms, scatter plots  
- **Basic math and numerical computations with NumPy**: vectors, matrices, matrix multiplication  
- **Practical data analysis exercises**: summarizing data, basic dataset analysis

## Month 1: Getting Started with Data Tools

**Goal**: Learn to read, inspect, and prepare data for small projects

### Week 1
- Introduction to data structures: Series and DataFrame
- Reading CSV files
- Inspecting and exploring data

### Week 2
- Selecting rows and columns
- Filtering data with conditions
- Sorting and limiting results

### Week 3
- Reading and writing Excel files
- Combining datasets
- Handling missing values

### Week 4
- Mini-project: Analyze a small dataset
- Example: Summarizing data, creating simple charts

## Month 2: Basic Math and Data Analysis

**Goal**: Build mathematical foundations and analysis skills applicable to Computer Vision

### Week 5
- Basic linear algebra: vectors, matrices, matrix multiplication
- Hands-on practice with NumPy

### Week 6
- Numerical computations and fundamental NumPy functions
- Data visualization: line plots, histograms, scatter plots

### Week 7
- Basic probability and statistics: mean, variance, distributions
- Practical exercises with NumPy and Pandas

### Week 8
- Mini-project: Analyze a real dataset
- Example: Data distribution, visualization, checking missing values
